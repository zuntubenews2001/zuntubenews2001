プライバシーポリシー

本ポリシーは、「ずんだ週間ニュース」（以下「本アプリ」）における情報の取り扱いについて定めるものです。

1. 本アプリの目的

本アプリは、運営者本人のYouTubeチャンネルへ動画をアップロードし、タイトル・説明文・公開設定などを管理するためにのみ使用します。

2. 取得する情報

本アプリは、YouTube Data API の利用に必要なGoogleアカウントの認証情報（アクセストークン等）のみを取得します。

3. 情報の利用と保存

取得した認証情報は、運営者が管理するコンピューター内にのみ保存し、上記の目的以外には使用しません。

4. 第三者への提供

取得した情報を第三者に販売・提供・共有することはありません。

5. Google APIの利用について

本アプリは YouTube API サービスを利用しています。YouTubeの利用には YouTube利用規約 が、Googleによる情報の取り扱いには Googleプライバシーポリシー が適用されます。

本アプリへのアクセス許可は、Googleアカウントのセキュリティ設定からいつでも取り消せます。
